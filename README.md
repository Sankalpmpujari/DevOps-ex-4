# DevOps Experiment 4: GitFlow Workflow

**Aim:** Implementing GitFlow Workflow in a Team-Based Scenario

This repository demonstrates the GitFlow branching model, managing feature development, releases, and hotfixes in a simulated collaborative team environment.

## Branching Strategy
- `main`: Production-ready code and official releases
- `develop`: Integration branch for day-to-day development
- `feature/*`: Specific features and modules
- `release/*`: Release candidate stabilization (e.g. `release/v1.0`)
- `hotfix/*`: Emergency fixes applied directly to production (e.g. `hotfix/bug-4`)
